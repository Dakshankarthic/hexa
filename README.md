# 🕷️ ESP32 Hexapod Spider Robot

A modern, cost-effective 3D-printed 18-DOF hexapod spider robot.

## Description

This project features a 3D-printed 6-legged robot (18-DOF total) built around a single ESP32 30-pin DevKit. By using two PCA9685 I²C servo drivers, it efficiently controls 18 MG996R servos for complex gaits and movements. 

Key features include:
- **ESP32 MCU:** High performance with built-in Wi-Fi and Bluetooth capabilities, eliminating the need for complex multi-board setups.
- **PCA9685 Servo Drivers:** Two drivers to manage 18 servos over an I²C bus.
- **Wi-Fi Control:** Enables remote piloting directly via a smartphone or web interface.
- **3D Printed Frame:** Fully 3D printed mechanical structure for customization and ease of assembly.
